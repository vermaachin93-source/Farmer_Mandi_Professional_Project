# Farmer Mandi – Professional College Mini Project

## Run the project
1. Extract the ZIP file.
2. Open the `farmer_mandi_pro` folder in VS Code.
3. Open `index.html` in a browser (recommended: VS Code Live Server).
4. Register a demo farmer account, then explore the dashboard.

## Features
- Farmer registration and login
- Dashboard overview
- Crop add, edit, remove and demo sale
- Mandi price sample table with search
- Crop value estimator
- Buyer listing creation and removal
- Transaction history
- Demo bank profile and farmer profile settings
- Browser LocalStorage persistence

## Important project limitations
- This is a frontend-only college mini project. Data is stored in the current browser using LocalStorage.
- Passwords are stored locally for demonstration only. This is NOT secure authentication and must not be used for real accounts.
- Mandi prices, buyer enquiries and transaction records are sample/demo data, not live data.
- The crop value estimator is arithmetic, not an AI/ML prediction.
- Bank details are demo fields only. Do not enter real bank account information.
- No real payment, bank verification, buyer messaging, GPS or live weather service is connected.

## Technology
HTML5, CSS3, JavaScript (Vanilla), LocalStorage, Font Awesome icons.

## Suggested future scope
Connect a backend (Node.js/Express or Python Flask), database, secure authentication, verified mandi price API, weather API, maps and real buyer messaging.
